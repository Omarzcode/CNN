# CNN — Computer Vision Learning Journey

This repo is where I'm learning **Computer Vision** by following **Andrew Ng's Deep Learning / CV courses**, and practicing what I learn by building small, focused detection and classification projects.

The goal isn't to build production-grade systems — it's to understand the fundamentals (convolutions, CNN architectures, object detection, etc.) by implementing them hands-on.

---

## 📚 What I'm Learning

- Convolutional Neural Networks (CNNs) — from scratch and with frameworks
- Image classification
- Object detection basics (bounding boxes, IoU, sliding windows, YOLO-style ideas)
- Data preprocessing & augmentation for vision tasks
- Model evaluation for CV tasks

## 🚀 Getting Started

Clone the repo:

```bash
git clone https://github.com/your-username/CNN.git
cd CNN
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Each project folder has its own instructions for running it — check the README inside that folder.
